恭喜完成课程！了解如何继续深入并把应用部署上线。

## 🎯 学习目标

- 回顾已掌握的能力
- 把应用部署上线并分享
- 了解继续学习的方向与资源

## 📋 步骤清单

### 1. 部署

把项目推到 GitHub，Vercel 会自动构建部署；之后每次推送到 `main` 分支都会自动重新部署。
记得在 Vercel 项目里配置好环境变量（数据库连接、`AUTH_SECRET` 等）。

### 2. 继续学习

- 官方文档：https://nextjs.org/docs
- 官方模板（Admin Dashboard / Commerce / Blog Starter / Chatbot / Image Gallery）
- Next.js 仓库：https://github.com/vercel/next.js
- Vercel YouTube / Reddit 社区

### 3. 分享

把你的作品分享给朋友或社区，并持续用「做项目」的方式练习。

## 💡 提示 / 易错点

- 部署前先在本地 `npm run build` 跑一遍，确保没有构建错误。
- 生产环境的环境变量要在托管平台单独配置，`.env` 不会自动上传。

## ✅ 完成标准

- [ ] 应用已部署，能通过公开链接访问
- [ ] 收藏了至少一个继续学习的资源
- [ ] 开始规划下一个自己的 Next.js 项目

## 🤖 交给 Agent 的引导规则

- Agent 只做讲解与提示，**不得**替你修改代码，**不得**替你运行命令。
- 可以和 Agent 聊聊「下一个想做什么项目」，让它帮你梳理技术选型与步骤。
